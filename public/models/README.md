# Models

Current room furniture is in `kenney-furniture/` and uses Kenney Furniture Kit GLB assets.

- Source: https://kenney.nl/assets/furniture-kit
- License: CC0 1.0 Universal, https://creativecommons.org/publicdomain/zero/1.0/

Place future `.glb` or `.gltf` room assets here.

To replace placeholder geometry, keep the interactive anchor positions from `src/components/scene/InteractiveObjects.tsx` and swap each object mesh group for a `useGLTF("/models/name.glb")` model.
